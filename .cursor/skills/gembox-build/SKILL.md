# Gembox build (maintainer)

**When:** Human says **gembox build** (any casing). **Do not** bootstrap a product prototype repo.

## Steps

1. **Confirm Notion MCP** — fetch **Skill builder (Cursor)** full body: https://www.notion.so/36050ba3919d802899e8cece5d2567ca
2. Follow the **Maintainer — refresh the precompiled pack** section on that page (regenerate skills, run pack bundler script from Notion, update **Skill pack A** and **Skill pack B**).
3. Confirm **Bootstrap (Cursor)** command map still matches.

**Consumers** use **gembox setup** / **gembox refresh** — they only read the published packs; they never run this skill unless they are maintaining Gembox itself.
